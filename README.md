# Toolie

A collection of useful web-based tools and utilities.

## Project Goals

Toolie aims to provide a centralized platform for various practical tools and calculators. The project focuses on delivering simple, fast, and accessible utilities for everyday tasks.

## Current Features

- **Salary Calculator**: Calculate net salary and deductions based on gross income inputs

## Tech Stack

- React 19
- TypeScript
- Vite
- Mantine UI
- Zustand (state management)
- React Router

## Development

```bash
# Install dependencies
bun install

# Start development server
bun run dev

# Build for production
bun run build
```
